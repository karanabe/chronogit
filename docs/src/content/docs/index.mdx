  <section class="landing-intro" aria-labelledby="landing-intro-title">
    <p class="landing-eyebrow">Read-only by design</p>
    <h2 id="landing-intro-title">Review a repository without leaving your terminal.</h2>
    <p>Move from the working tree to a commit, its complete message, changed files, and tree without assembling several Git commands. ChronoGit only issues a closed set of read commands and never stages, restores, commits, or checks out.</p>
  </section>

  <div class="landing-principles" aria-label="ChronoGit capabilities">
    <section>
      <span aria-hidden="true">01</span>
      <h3>Inspect current work</h3>
      <p>Read tracked and untracked, unstaged changes with line numbers and binary summaries.</p>
    </section>
    <section>
      <span aria-hidden="true">02</span>
      <h3>Walk commit history</h3>
      <p>Open first-parent patches, full messages, and lazily loaded repository trees.</p>
    </section>
    <section>
      <span aria-hidden="true">03</span>
      <h3>Stay in control</h3>
      <p>Use bounded Git reads, responsive layouts, and familiar Vim-oriented keys.</p>
    </section>
  </div>
