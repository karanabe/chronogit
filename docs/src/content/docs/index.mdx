  <section class="landing-intro" aria-labelledby="landing-intro-title">
    <p class="landing-eyebrow">Browse and switch branches</p>
    <h2 id="landing-intro-title">Review a repository without leaving your terminal.</h2>
    <p>Move from the working tree or repository search to source code, a commit, its complete message, changed files, and tree without assembling several Git commands. Browsing is read-only. When needed, switch an existing local branch from any view with Space b.</p>
  </section>

  <div class="landing-principles" aria-label="ChronoGit capabilities">
    <section>
      <span aria-hidden="true">01</span>
      <h3>Inspect current work</h3>
      <p>Read tracked and untracked, unstaged changes with line numbers and binary summaries.</p>
    </section>
    <section>
      <span aria-hidden="true">02</span>
      <h3>Walk commit history</h3>
      <p>Follow parent lanes, open first-parent patches, then move through changed symbols into the complete new-state file.</p>
    </section>
    <section>
      <span aria-hidden="true">03</span>
      <h3>Browse source safely</h3>
      <p>Expand the working-tree hierarchy, read syntax-highlighted files, and use opt-in LSP document symbols to jump through them.</p>
    </section>
  </div>
