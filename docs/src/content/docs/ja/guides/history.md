Historyビューでは、ページ分割されたコミット一覧と、各コミットの変更ファイル、パッチ、メッセージ全文、リポジトリツリーをまとめて確認できます。

`chronogit --view history`または`2`キーで開きます。

## コミットとファイルを選ぶ

Historyは上からコミット、変更ファイル/ツリー、差分プレビューの3段を全幅で表示します。

1. 上段で`j`と`k`を使い、コミットを選びます。
2. `Enter`でコミットを確定し、変更ファイルへフォーカスを移します。`l`または`Ctrl-j`でも移動できます。
3. `Enter`で完全なパッチを大きな差分フロートに開きます。
4. `j` / `k`、`Ctrl-d` / `Ctrl-u`、`g` / `G`で現在行を示すガターマーカーを移動し、表示範囲を追従させます。シンタックスハイライトされたコードの行全体は塗り替えません。差分の読み込み中に入力したキーも、表示された時点で反映されます。`/`または`?`で前方/後方検索し、`n` / `N`で一致を移動できます。
5. もう一度`Enter`を押すか、`q` / `Esc`で差分を閉じます。

履歴は200コミットずつ読み込みます。続きがあるときに読み込み済みページの末尾へ移動すると、次のページを要求します。変更ファイル一覧と差分は、選択したコミットについてだけ読み込みます。

## 比較元を理解する

現在の比較元は、変更ファイルと差分のタイトル、およびフッターに表示されます。

| コミットの種類 | 比較 |
| --- | --- |
| ルートコミット | 空のツリー → 選択コミット |
| 通常コミット | 親 → 選択コミット |
| マージコミット | first parent → 選択したマージコミット |

`0.2.0`ではマージコミットを結合差分や親ごとの差分として表示しません。別の親との比較が必要な場合はGitを併用してください。

## コミットメッセージ全文を読む

`m`を押すと、選択コミットのメッセージ全文がフローティングオーバーレイで開きます。移動キーでメッセージをスクロールできます。もう一度`m`を押すか、`q` / `Esc`で閉じます。

本文を常時表示するレイアウトが必要な場合は`b`を押します。上から、通常と同じ操作可能なコミット一覧、trailerを含む選択コミットの本文、変更ファイル一覧の3段です。`h` / `l`または`Ctrl-k` / `Ctrl-j`でフォーカスを移します。上段で別コミットを選ぶと、本文とファイル一覧も更新されます。下段で`Enter`を押すとファイル差分が開き、差分内は`j` / `k`で移動できます。もう一度`b`を押すと通常のHistoryへ戻ります。

## Graphで親レーンをたどる

`3`を押すか`chronogit --view graph`で起動すると、同じページ分割コミットを親レーン付きで表示します。`j` / `k`でコミットを変え、`m`でメッセージ全文を開けます。`Enter`を押すと、Graphの上にそのコミットの変更ファイルと選択ファイル差分を上下2段のフロートで表示します。もう一度`Enter`を押すと差分全文を開き、`q` / `Esc`で1段ずつ戻ります。

## コミットツリーをたどる

`t`を押すと、変更ファイル一覧が選択コミットの完全なツリーに切り替わります。

- ディレクトリを選び、`Enter`で展開・折りたたみます。
- ファイルを選んで`Enter`を押すと、現在のコミット比較におけるパッチを開きます。
- 変更されていないファイルも選択できますが、そのコミットでは変更がないことを表示します。
- シンボリックリンクとサブモジュールはGitツリーモードから識別します。
- ChronoGitはサブモジュールのリポジトリ内へ入りません。

ツリーのディレクトリは必要になった時点で読み込みます。同じコミットで展開済みのディレクトリへ戻ると、その内容を再利用します。

もう一度`t`を押すと変更ファイルへ戻ります。コミットを変えると、新しいコミットのルートから表示します。
