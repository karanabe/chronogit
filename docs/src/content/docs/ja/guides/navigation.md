ChronoGitはキーボードだけで操作できます。アプリ内で`F1`を押すと短いキー一覧を表示します。

## キー一覧

| キー | 操作 |
| --- | --- |
| `q` | 現在のフロートを即座に閉じる、または戻る |
| `Esc` | 入力をキャンセル。Diff・Codeでは検索強調を解除してから、次のEscでclose/back |
| `Q` / `Ctrl-C` | 終了 |
| `\1` / `\2` / `\3` / `\4` | Changes / History / Graph / Codeを開く |
| `\f` / `\g` | リポジトリのファイル名 / ワークツリー内容を検索 |
| `Ctrl-w h/k` / `Ctrl-w j/l` | 前 / 次のペインへフォーカス（`Ctrl-w W/w`、control文字、Backspace、矢印も使用可能） |
| `[count]h/j/k/l`、矢印 | 文字または論理行単位で移動 |
| `[count]Space`、`[count]Backspace` / `Ctrl-H` | Vim標準の`'whichwrap'`同様、行をまたいで文字移動 |
| `w/W/e/E`、`b/B/ge/gE` | word / 空白区切りWORD単位で移動（`Shift-←/→`は`b/w`、`Ctrl-←/→`は`B/W`） |
| `0`、`^`、`$`、`g_`、`g0`、`g^`、`g$`、`g<End>`、`gm`、`gM`、<code>\|</code> | 行と画面列の移動 |
| `f/F/t/T{char}`、`;` / `,` | 文字をfind/tillし、同方向 / 逆方向へ反復 |
| `gg`、`G`、`Ctrl-Home/End`、`[count]%`、`go`、`H/M/L` | バッファ行・割合・バイト位置・画面行へ移動 |
| `(`/`)`、`{`/`}`、`[[`/`]]`、`[]`/`][` | 文、段落、section単位で移動 |
| `%` / `g%`、`[( / [{`、`]) / ]}`、`[m/M / ]m/M`、`[# / ]#`、`[* / ]*`、`[/ / ]/` | 正方向/逆方向の対応記号、method、preprocessor、commentへ移動 |
| `Ctrl-d/u`、`Ctrl-f/b`、PageUp/Down、`Ctrl-e/y` | 半 / 全ページと1行のviewport移動 |
| `zt/zz/zb`、`z<CR>/z./z-`、`z+/z^`、`zh/zl/zH/zL/zs/ze` | cursor相対と横方向のviewport移動 |
| `[c` / `]c` | 前 / 次のdiff変更ブロックへ移動 |
| `m{char}`、`'{char}`、`` `{char}``、`g'{char}`、`` g`{char}`` | Code markを設定し、行 / 正確な列へjump。`g`版はjump listを維持 |
| `['` / `` [` ``、`]'` / `` ]` `` | 前 / 次の小文字Code markへ行単位 / 正確に移動 |
| `r` | 現在のビューを更新 |
| `\m` / `\b` / `\t` | メッセージ全文 / History本文レイアウト / commit treeを切り替え |
| `Enter` | 選択項目を確定/開く。テキスト全文では`+`と同じ移動 |
| `/` / `?`、`n` / `N`、`*` / `#`、`g*` / `g#` | アクティブなテキスト内を検索 |
| `K` | Code cursor位置のLSP hoverを開閉 |
| `gd` / `gi`、`gy` / `gD` | LSPの定義 / 実装、型定義 / 宣言 |
| `[count]Ctrl-o` / `[count]Ctrl-i` | 古い / 新しいVim・LSP jump位置へ移動 |
| `F1` | アプリ内ヘルプを開く / 閉じる |

数値countはVim motion、文字検索、検索反復、jump list移動に適用されます。`gg`、`zh`、`\f`などの連続キーは750 ms以内に入力します。`f`、`t`、`m`、apostrophe、backtickは文字引数を時間制限なく待ちます。連続キーのprefix後に別のキーを押した場合、そのキーは通常どおり処理されます。これは組み込み標準キーです。[キーマップ設定](/ja/reference/keymap/)で変更できます。

互換範囲は、ChronoGitのread-onlyなテキスト / listビューに適用できるVim normal modeの移動です。編集operator、Insert / Visual mode、編集可能bufferを必要とする移動は意図的に対象外です。

## ペインの動作

Changesにはファイルと差分のペインがあります。通常のHistoryは、コミット、変更ファイル/ツリー、差分の3段を全幅で縦に並べます。`\b`を押すと、同じ操作可能なコミット一覧、コミット本文、変更ファイルを3段に並べた別レイアウトへ切り替わります。Graphは親関係のレーン一覧を全高で表示し、コミット詳細はその上に2段のフロートとして開きます。Codeは展開可能なワークツリーのファイルツリーを上段、選択ファイル内容を下段に常に配置します。Code以外から開いたファイル検索結果は上段に履歴、下段に内容/差分を表示します。

- 110列以上ではChangesの2ペインを同時に表示します。
- 80〜109列ではChangesのフォーカス中ペインが横幅を使います。Historyは3段表示を維持します。
- 80列未満または24行未満では通常画面を最小サイズの案内に置き換えます。`Q`と`Ctrl-C`は引き続き使えます。
- 十分に幅がある場合、フッターには解決済みのリポジトリルートも表示します。

強調された枠線がフォーカス中のペインです。選択とスクロールはそのペインに作用します。テキストペインの`h` / `l`はVim文字移動、listだけのcontextでは隣接ペイン選択です。`Ctrl-w h/k/j/l`は常にペインフォーカスを動かします。Historyのコミットペインでは、`Enter`で選択中のコミットを確定し、変更ファイルへ直接フォーカスを移せます。

## オーバーレイ

ヘルプ、Graph詳細、リポジトリ検索、コミットメッセージ全文、現在のファイル内容、Codeファイル、選択ファイルの差分はメインのペイン上に表示されます。メッセージはもう一度`\m`を押して閉じられます。テキストoverlayでもVimの文字cursorとmotionを維持します。`Enter`は`+`と同様に次行の最初の非空白へ移動し、`q`でoverlayを即座に閉じます。`Esc`はDiff・Codeの検索強調を先に解除し、次のEscで閉じます。リポジトリ検索では、`Enter`または`Ctrl-j`でSearchからResultsへ移り、`Ctrl-w k`で現在のクエリを維持したままSearchへ戻って再編集できます。文字入力中でなければ、`q`は現在のフロートを閉じるか、詳細/ファイル画面から戻ります。検索強調がない状態の`Esc`も同じ動作です。検索prompt入力中は`q`と`Q`をクエリ文字として入力でき、`Esc`で入力をキャンセルし、`Ctrl-C`で終了します。`/`が前方検索、`?`が後方検索で、count付き`n` / `N`は末尾・先頭をまたいで反復します。`*` / `#`はcursor位置のword全体、`g*` / `g#`は部分一致を検索します。小文字だけのクエリは大文字小文字を区別せず、大文字を含むクエリは区別します。

文書内検索（`/`・`?`）では、Backspaceで末尾の文字を削除します。最後の文字を消した直後は空のpromptを保つため、そのまま別の語を入力できます。空の状態でもう一度Backspaceを押すと入力を取り消します。Escは入力の有無にかかわらずキャンセルします。入力カーソル（`█`）が消え、画面・フォーカス・本文カーソル・縦横のスクロール位置と、前回の確定検索の語・方向・一致情報・強調の表示状態を保ちます。`n` / `N`で前回の検索を再開でき、空のpromptでEnterを押すと前回の語を使って検索します。`/word 1/3`等の確定検索の状態欄が残っていても、入力待ちではありません。リポジトリ検索（`\f`・`\g`）の操作は変わりません。

## 終了時のターミナル復元

起動時エラーはraw modeを有効にする前に発生し、ターミナルへ触れません。TUI開始後の通常終了、`Q`、`Ctrl-C`、実行時エラー、panicでは、raw mode、カーソル、マウスキャプチャ、alternate screenを復元する設計です。強制終了や端末障害の後にシェル表示が戻らない場合は、[トラブルシューティング](/ja/troubleshooting/common-problems/#ターミナルが復元されない)を参照してください。

Diff・Codeの通常ペインとフロートでは、一致文字列だけを強調します。現在の一致は黄色背景、他の一致は下線、カーソルは水色です。標準`Esc`で検索由来の装飾だけを消し、検索語・方向・フォーカス・カーソル・スクロール位置を保って読み続けられます。`n` / `N`または次の確定検索で強調が戻ります。一致なしの場合は追加のEscを要求しません。promptやfind/till・markの文字待ちでは入力キャンセルを優先し、直前の検索と強調の表示・解除状態を保ちます。ヘルプ・hover・リポジトリ検索が最前面なら、その画面を先に閉じます。
