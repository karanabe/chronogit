ChronoGitはキーボードだけで操作できます。アプリ内で`F1`を押すと短いキー一覧を表示します。

## キー一覧

| キー | 操作 |
| --- | --- |
| `q` / `Esc` | 現在のフロートを閉じる、または戻る |
| `Q` / `Ctrl-C` | 終了 |
| `1` / `2` / `3` | Changes / History / Graphを開く |
| `Space f` / `Space g` | リポジトリのファイル名 / ワークツリー内容を検索 |
| `h` / `l` | 前 / 次のペインへフォーカスを移す |
| `Ctrl-k` / `Ctrl-j` | 前 / 次のペインへフォーカスを移す |
| `j` / `k`または`↓` / `↑` | 選択またはスクロールを下 / 上へ移動 |
| `g` / `G`または`Home` / `End` | 先頭 / 末尾へ移動 |
| `Ctrl-d` / `Ctrl-u` | 半ページ下 / 上へ移動またはスクロール |
| `zh` / `zl` | 差分を左 / 右へスクロール |
| `r` | 現在のビューを更新 |
| `m` | コミットメッセージ全文のオーバーレイを開く / 閉じる |
| `b` | Historyの差分 / 本文レイアウトを切り替え |
| `t` | 変更ファイル / コミットツリーを切り替え |
| `Enter` | 選択項目を確定/開く、または全文フロートを閉じる |
| `/` / `?` | 差分フロートを前方 / 後方検索 |
| `n` / `N` | 次 / 前の検索一致へ移動 |
| `F1` | アプリ内ヘルプを開く / 閉じる |

`zh`、`zl`、`Space f`、`Space g`は750 ms以内に続けて入力します。連続キーのprefix後に別のキーを押した場合、そのキーは通常どおり処理されます。これは組み込み標準キーです。[キーマップ設定](/ja/reference/keymap/)で変更できます。

## ペインの動作

Changesにはファイルと差分のペインがあります。通常のHistoryは、コミット、変更ファイル/ツリー、差分の3段を全幅で縦に並べます。`b`を押すと、同じ操作可能なコミット一覧、コミット本文、変更ファイルを3段に並べた別レイアウトへ切り替わります。Graphは親関係のレーン一覧を全高で表示し、コミット詳細はその上に2段のフロートとして開きます。ファイル検索結果は上段に履歴、下段に内容/差分を表示します。

- 110列以上ではChangesの2ペインを同時に表示します。
- 80〜109列ではChangesのフォーカス中ペインが横幅を使います。Historyは3段表示を維持します。
- 80列未満または24行未満では通常画面を最小サイズの案内に置き換えます。`Q`と`Ctrl-C`は引き続き使えます。
- 十分に幅がある場合、フッターには解決済みのリポジトリルートも表示します。

強調された枠線がフォーカス中のペインです。選択とスクロールはそのペインに作用し、`h` / `l`または`Ctrl-k` / `Ctrl-j`がフォーカスを動かします。Historyのコミットペインでは、`Enter`で選択中のコミットを確定し、変更ファイルへ直接フォーカスを移せます。

## オーバーレイ

ヘルプ、Graph詳細、リポジトリ検索、コミットメッセージ全文、現在のファイル内容、選択ファイルの差分はメインのペイン上に表示されます。メッセージはもう一度`m`を押して閉じられます。メッセージ、内容、差分は移動キーでスクロールでき、内容と差分は開いたときと同じ`Enter`で閉じられます。リポジトリ検索では、`Enter`または`Ctrl-j`でSearchからResultsへ移り、`Ctrl-k`で現在のクエリを維持したままSearchへ戻って再編集できます。文字入力中でなければ、`q`と`Esc`は現在のフロートを閉じるか、詳細/ファイル画面から戻ります。リポジトリ検索または差分検索のprompt入力中は`q`と`Q`をクエリ文字として入力でき、`Esc`で入力をキャンセルし、`Ctrl-C`で終了します。リポジトリ検索promptのキャンセルではoverlayも閉じます。差分フロートでは`j` / `k`で現在行を示すガターマーカーを上下へ移動し、コードの色を塗り替えずに表示範囲が追従します。`Ctrl-d` / `Ctrl-u`は半ページ移動し、差分の読み込み中に入力した場合も表示後に反映されます。`/`が前方検索、`?`が後方検索です。クエリを入力して`Enter`で確定し、`n` / `N`で強調された一致を末尾から先頭へ折り返しながら移動します。小文字だけのクエリは大文字小文字を区別せず、大文字を含むクエリは区別します。

## 終了時のターミナル復元

起動時エラーはraw modeを有効にする前に発生し、ターミナルへ触れません。TUI開始後の通常終了、`Q`、`Ctrl-C`、実行時エラー、panicでは、raw mode、カーソル、マウスキャプチャ、alternate screenを復元する設計です。強制終了や端末障害の後にシェル表示が戻らない場合は、[トラブルシューティング](/ja/troubleshooting/common-problems/#ターミナルが復元されない)を参照してください。
