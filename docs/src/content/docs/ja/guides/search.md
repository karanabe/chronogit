リポジトリ検索はどのメインビューからでも開けます。追跡済み・未追跡ファイルのパス検索は`Space f`、バイナリ以外のワークツリーファイルに対する固定文字列検索は`Space g`です。

## ファイルを探して開く

1. クエリを入力します。文字の挿入または削除ごとに結果が更新されます。ファイル検索の空クエリは編集後または`Enter`で全ファイルを表示し、内容検索の空クエリは一致なしになります。
2. `Enter`または`Ctrl-j`で文字入力を終了し、現在のResultsへフォーカスを移します。
3. `j` / `k`、`gg` / `G`、矢印キー、Home/Endで結果を移動します。
4. `Ctrl-k`でSearchへ戻って現在のクエリを再編集するか、`Enter`で選択結果を開きます。内容検索から開いた場合は、最初に一致行を強調します。Codeから始めた検索はCodeへ直接戻り、ツリー内のファイルを表示します。それ以外のビューからはファイル履歴画面を開きます。

ファイル名検索はsmart-caseです。小文字だけなら大文字小文字を区別せず、大文字を含む場合は区別します。内容検索は大文字小文字を区別する固定文字列検索で、正規表現として解釈しません。追跡済みファイルと、ignoreされていない未追跡ファイルを対象にし、バイナリとサブモジュール内は検索しません。

## 現在内容と履歴を比較する

ファイル画面は、上段にそのパスへ影響した最大200コミット、下段にシンタックスハイライトした現在のワークツリー内容を表示します。現在行のガターマーカーはトークンの色を塗り替えません。シンボリックリンク、バイナリ、削除済みパス、サブモジュールは、対象をたどったりデコードしたりせず要約を表示します。

上段で`j` / `k`を使って選択コミットを変えると、下段はそのコミットとfirst parentの差分に切り替わります。ルートコミットは空ツリーと比較します。`h` / `l`でペインを移動し、`Enter`で表示中の現在内容または差分を大きなフロートに開きます。`q`または`Esc`を1回押すとフロートを閉じ、もう1回押すと検索を始めたビューへ戻ります。検索promptの入力中は`q`と`Q`をクエリ文字として入力でき、`Esc`でpromptをキャンセルし、`Ctrl-C`で終了します。

検索とファイル読み取りにも、ChronoGitの読み取り専用動作、8 MiBの出力/内容上限、30秒のGitタイムアウト、同時読み取り最大2件が適用されます。
