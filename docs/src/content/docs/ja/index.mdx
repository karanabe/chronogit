    <p class="landing-eyebrow">設計から読み取り専用</p>
    <h2 id="landing-intro-title">ターミナルを離れずに、リポジトリをレビュー。</h2>
    <p>ワークツリーやリポジトリ検索からソースコード、コミット、メッセージ全文、変更ファイル、ツリーまでを、複数のGitコマンドを組み立てずにたどれます。ChronoGitが行うのは読み取りだけで、ステージ、復元、コミット、チェックアウトは行いません。</p>
  </section>

  <div class="landing-principles" aria-label="ChronoGitでできること">
    <section>
      <span aria-hidden="true">01</span>
      <h3>現在の作業を読む</h3>
      <p>追跡済み・未追跡の未ステージ変更を、行番号やバイナリ要約とともに確認できます。</p>
    </section>
    <section>
      <span aria-hidden="true">02</span>
      <h3>コミットをたどる</h3>
      <p>親レーンをたどり、first-parent差分、メッセージ全文、ファイル単位の履歴を開けます。</p>
    </section>
    <section>
      <span aria-hidden="true">03</span>
      <h3>ソースを安全に閲覧</h3>
      <p>ワークツリー階層を展開し、上限付きでlinkをたどらない読み取りによりsyntax highlightされたファイルを確認できます。</p>
    </section>
  </div>
